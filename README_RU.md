# Home Credit Default Risk — SQL Analysis

## Бизнес-задача
Home Credit Group выдает кредиты клиентам с небольшой или отсутствующей 
кредитной историей. Основная задача — определить, какие клиенты с высокой 
вероятностью могут допустить дефолт еще до одобрения кредита. В рамках 
проекта был проведен анализ поведения клиентов для выявления факторов, 
влияющих на невозврат кредита, а также определения ключевых риск-индикаторов, 
которые следует учитывать при принятии решения о выдаче займа.

## Бизнес-вопросы
1. Каков общий уровень дефолта и насколько сбалансирован датасет?
2. Чаще ли допускают дефолт клиенты с плохой платежной историей?
3. Влияют ли доход или размер кредита на вероятность дефолта?
4. Помогает ли предыдущая кредитная история предсказывать текущий дефолт?
5. Какие факторы являются наиболее сильными индикаторами кредитного риска?

## Этапы анализа
1. Импортированы 4 CSV-файла в PostgreSQL через DBeaver
2. Выполнена обработка пропущенных значений с использованием COALESCE
3. Выполнена агрегация кредитной истории клиентов (`bureau_agg`)
4. Выполнена агрегация предыдущих кредитных заявок (`prev_appl_agg`)
5. Выполнена агрегация истории платежей (`inst_payments`)
6. Все таблицы объединены с основной таблицей заявок через LEFT JOIN
7. Проведен exploratory data analysis для сравнения клиентов с дефолтом и без дефолта

## Использованные SQL-навыки
- LEFT JOIN для объединения 4 таблиц
- Агрегации (SUM, COUNT, MAX, AVG)
- CASE WHEN для условного подсчета
- COALESCE для обработки NULL-значений
- GROUP BY и ROUND
- CREATE TABLE AS SELECT

Основные выводы

1. Уровень дефолта: 8.07%

Только 1 из 12 клиентов допускает дефолт. Датасет сильно несбалансирован,
поэтому обычная accuracy может вводить в заблуждение. При построении
риск-моделей необходимо учитывать дисбаланс классов.

2. Платежное поведение — самый сильный индикатор риска

Клиенты с дефолтом в среднем чаще пропускают платежи (5 против 4),
а также имеют на 40% более высокую максимальную просрочку
(8,922 против 6,359). Плохая платежная дисциплина является одним
из главных ранних признаков будущего дефолта.

3. Доход и размер кредита — слабые индикаторы

У клиентов с дефолтом доход и сумма кредита лишь незначительно ниже.
Эти различия слишком малы, чтобы использовать их как надежные
индикаторы риска отдельно от других факторов.

4. Кредитная история имеет значение

Клиенты с высокой исторической просрочкой значительно чаще допускают
дефолт, что подтверждает: прошлое поведение клиента помогает
прогнозировать будущее.

5. Рекомендации

История платежей и уровень просрочек являются более сильными
индикаторами риска, чем доход или размер кредита. Кредитные заявки
клиентов с частыми пропусками платежей или высокой исторической
просрочкой должны проходить дополнительную проверку перед одобрением кредита.
